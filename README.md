# GWAP Origin

Independent digital-asset provenance and verification infrastructure for GWAP and external applications.

> Status: early development. No production verification, C2PA signing, hidden watermark, public upload, payment, or PPV mainnet capability is enabled.

Initial implementation work is proposed through pull requests. Verification must remain neutral: registrations, creator declarations, C2PA evidence, and blockchain timestamps are distinct claims and are never proof of copyright ownership or truth by themselves.
